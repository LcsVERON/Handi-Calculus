RÈGLE ABSOLUE SUR GIT
Je fais tous les commits moi-même pour vérifier ton travail.
- N'exécute JAMAIS : git commit, git push, git add, git reset, git checkout,
  git stash, git rebase, git merge, ni aucune commande qui modifie l'historique,
  l'index ou la configuration git.
- Tu peux seulement utiliser git status et git diff pour voir l'état.
- Ne crée pas de branche.
